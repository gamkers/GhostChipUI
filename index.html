User Guide

DuckyScript Syntax

DuckyScript is the industry standard for BadUSB payloads. It consists of simple commands that represent keystrokes.

Core Commands
DELAY [ms]Pauses the script for the specified milliseconds. Essential for timing.
STRING [text]Types the specified text exactly as provided.
ENTERPresses the Enter/Return key.
GUI [key]Presses the System/Windows/Command key + another key.
REM [text]Comment line. Ignored during execution.
DEFAULTDELAY [ms]Sets a delay between every single command.
Modifier Keys
CTRL / CONTROLThe Control key.
ALTThe Alt / Option key.
SHIFTThe Shift key.
CAPSLOCKToggles Caps Lock.
Special Keys
TABThe Tab key.
ESCAPE / ESCThe Escape key.
SPACEThe Space bar.
UP / DOWN / LEFT / RIGHTArrow keys.
PAGEUP / PAGEDOWNPage navigation keys.
HOME / ENDCursor navigation keys.
F1 - F12Function keys.
Feature Guide
Script Builder

A visual interface to create scripts. Select a command block, fill in the details, and add it to your script buffer.

Payload Queue

Allows you to chain multiple scripts together with custom delays. Great for complex multi-stage attacks.

Simulator

A real-time preview of what your script will do. It shows the keystrokes and timing without actually executing on the host.

NeoPixel Control

Change the color and brightness of the onboard LED to indicate status or for stealth mode.

Advanced Tips
Stealth Tip: Use DEFAULTDELAY 0 and manual DELAY commands for the fastest possible execution while maintaining reliability.
  • Use REM liberally to explain what your script does.
  • Always test new scripts in the Simulator before deployment.
  • For Windows, use PowerShell for exfiltration. For Mac, use Curl or Terminal.
