📖 Quick Start & Core Commands

GhostChip ESP32-S3 emulates standard USB HID keyboards and serial control interfaces to deliver automated penetration testing scripts (DuckyScript format).

  • REM [comment] — Line comment for notes
  • DELAY [ms] — Pause script execution in milliseconds
  • STRING [text] — Inject keystrokes as text
  • GUI [key] / WINDOWS [key] — Windows Key / Command Key combo
  • ENTER / TAB / ESC — Special key presses
  • REPEAT [count] — Repeat preceding command line N times
